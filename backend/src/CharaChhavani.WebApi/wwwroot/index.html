API Explorer उघडा

शेतकरी ॲप (Farmer Mobile App)
शेतकरी लॉगिन (OTP), प्रोफाईल, ७/१२ नोंद, जनावरांची छावणी प्रवेशासाठी पूर्व-नोंदणी (टॅग/फोटो) आणि अर्जाची थेट स्थिती.
🩺
पशुवैद्यकीय डॉक्टर ॲप (Vet Doctor App)
शेतकऱ्यांच्या गोठ्यावर जाऊन प्रत्यक्ष तपासणी, आरोग्य दाखला, लसीकरण स्थिती आणि जिओटॅगिंगसह मंजुरी/नकार अहवाल.
⛺
छावणी चालक ॲप (Camp Operator App)
कडक जिओफेन्स (Rule 9.6) अंतर्गत जनावरे छावणीत दाखल करणे, सोडवणूक पावती, चारा खरेदी वजन काटा नोंद व दैनंदिन खर्च नोंदणी.
📋
महसूल तपासणी अधिकारी (Officer App)
छावणीत अचानक भेट देऊन प्रत्यक्ष जनावरांची मोजणी, प्रणालीतील संख्येसोबत तफावत तपासणी, पाणी व चारा दर्जा ऑडिट.
